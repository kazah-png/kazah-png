# kazah-png

**Desarrollo de sistemas · C++ · herramientas nativas para Windows**

Actualmente trabajo en **[RETSAR](https://github.com/kazah-png/RETSAR)**, un proyecto open source para crear espacios de trabajo independientes en un mismo equipo Windows.

## RETSAR

RETSAR (*Runtime Environment for Terminal Sharing and Allocation of Resources*) explora cómo ejecutar y gestionar escritorios Windows nativos independientes, con sus propias aplicaciones e interacción, mientras el escritorio principal permanece disponible.

El proyecto está en fase de *development preview*. Ya incluye una consola nativa para gestionar escritorios, pantallas, dispositivos y actividad, además de experimentos verificados con escritorios secundarios e interacción de entrada. Aún no es una solución multiseat de producción: quedan por validar la asignación exclusiva de dispositivos, la recuperación fiable y la compatibilidad en más entornos.

- **Lenguaje y plataforma:** C++17 y Windows x64.
- **Enfoque:** escritorios secundarios, gestión de recursos y validación con evidencia reproducible.
- **Estado actual:** desarrollo activo.

## NyxOS — desarrollo pausado

[NyxOS](https://github.com/nyxos-dev/nyx-os) fue mi proyecto de sistema operativo x86_64 en C y Assembly, con entorno gráfico, red TCP/IP y espacio de usuario de estilo POSIX.

He pausado su desarrollo porque todavía no tengo los conocimientos necesarios para abordar con rigor los siguientes pasos del proyecto. Sigo documentándome y aprendiendo sobre sistemas operativos, arquitectura, compiladores y desarrollo de bajo nivel con la intención de retomarlo cuando cuente con una base más sólida.
